Technical Documentation

We prepare technical documentation in the structure that notified bodies and regulators expect, and check that the product description, risk management, test evidence and labeling agree with each other.

What we do

  • Technical file structureWe organize the table of contents and supporting evidence to the structure your target market expects.
  • GSPR conformityWe link each general safety and performance requirement to the applied standard and the evidence.
  • Clinical evaluation supportWe support the clinical evaluation plan (CEP) and clinical evaluation report (CER).
  • Labeling and IFU reviewWe check that labeling and instructions for use match the risk management results and the technical file.
  • Deficiency responsesWe support the written responses to notified body and regulator questions.

When to contact us

  • You are preparing a technical file for EU MDR or Korean approval for the first time
  • You want to check whether an existing file meets MDR requirements
  • You received a nonconformity or a request for additional information

Related standards and regulations

  • EU MDR Annex II·III
  • MFDS technical file review
  • GSPR checklist
  • Clinical evaluation (CEP, CER)
  • SSCP
