Cybersecurity

We identify threats to your device software and organize the cybersecurity documents and evidence a submission needs, from security requirements and architecture to testing and post-market management.

What we do

  • Threat modeling and security risk assessmentWe identify assets, interfaces and attack paths and assess security risk.
  • Security requirements and architecture reviewWe review the security requirements and design that respond to the identified risks.
  • SBOM and vulnerability managementWe prepare the software bill of materials (SBOM) and a vulnerability monitoring plan.
  • Security test planning and result reviewWe review plans and results of vulnerability scans and penetration tests and link them to the evidence.
  • Post-market security managementWe set up the patching and vulnerability response procedures.
  • Submission documentsWe prepare cybersecurity documents for FDA, EU MDR and Korean MFDS submissions.

When to contact us

  • You are developing software that connects to a network or exchanges data
  • You must prepare cybersecurity documents before an FDA or EU submission
  • You need to set up an SBOM and vulnerability management for the first time
